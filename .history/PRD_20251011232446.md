## 🎯 핵심 요구사항

### 1. 기술 스택
- **Frontend Framework**: React + TypeScript
- **스타일링**: CSS3 / Styled-components
- **빌드 도구**: Vite
- **배포**: GitHub Pages
- **반응형**: Mobile First 디자인

### 2. 필수 기능 (MVP)

#### 2.1 메인 페이지
- **인트로 섹션**
  - 커버 이미지 (메인 사진)
  - 신랑/신부 이름
  - 결혼식 날짜 표시
  
#### 2.2 초대 메시지 섹션
- 신랑/신부의 인사말 텍스트
- 우아한 폰트와 레이아웃

#### 2.3 일정 및 장소 정보
- **날짜 및 시간 표시**
  - D-Day 카운터 (2026년 1월 25일까지)
  - 날짜: 2026년 1월 25일 토요일
  - 시간: 오후 2시 30분
  
- **장소 정보**
  - 예식장 이름 및 층/홀 정보
  - 주소
  - 전화번호
  - 지도 연동 (네이버 지도, 카카오맵)
  - 길찾기 버튼 (카카오내비, 네이버지도, T맵)

#### 2.4 갤러리 섹션
- 이미지 갤러리 (최소 10장 이상 지원)
- 이미지 클릭 시 확대 보기 (라이트박스 기능)
- 좌우 스와이프 또는 버튼으로 이동
- 이미지 lazy loading 적용
- 임시 플레이스홀더 이미지 사용 (실제 사진은 추후 교체)

#### 2.5 연락하기 섹션
- 신랑/신부 및 양가 부모님 연락처
- 전화 아이콘 클릭 시 바로 전화 연결
- SMS 문자 보내기 버튼

#### 2.6 마음 전하기 (축의금 정보)
- 신랑/신부 계좌번호
- 양가 부모님 계좌번호
- 계좌번호 복사 버튼
- 카카오페이 송금 링크 (선택사항)

#### 2.7 방명록 / 축하 메시지
- 하객들이 축하 메시지를 남길 수 있는 섹션
- **방법 1**: Google Forms 임베드
- **방법 2**: Firebase Realtime Database 연동
- **방법 3**: GitHub Issues를 활용한 댓글 시스템

#### 2.8 공유 기능
- 카카오톡 공유하기 버튼
- URL 복사 버튼
- 클립보드 복사 피드백

## 🎨 디자인 요구사항

### 1. 반응형 디자인
- **모바일 최적화** (320px ~ 480px)
- 태블릿 지원 (481px ~ 768px)
- 데스크톱 지원 (769px 이상)

### 2. UI/UX
- **컬러 스키마**
  - 메인 컬러: 파스텔 톤 또는 우아한 색상
  - 서브 컬러: 보색 또는 중립색
  
- **폰트**
  - 한글: Noto Sans KR, Nanum Myeongjo, Gowun Batang 등
  - 영문: Playfair Display, Cormorant, Great Vibes 등
  
- **애니메이션**
  - 스크롤 시 Fade-in 효과
  - 부드러운 페이지 전환
  - 과도하지 않은 자연스러운 애니메이션

### 3. 이미지
- 임시 이미지: Unsplash / Pexels의 웨딩 이미지 사용
- 실제 사진은 추후 교체 가능하도록 구조 설계
- 이미지 최적화 (WebP 포맷 사용 권장)
- Lazy loading 적용

## 🔧 기술적 요구사항

### 1. 성능
- **로딩 속도**: 3초 이내 First Contentful Paint
- **이미지 최적화**: 압축 및 WebP 변환
- **코드 스플리팅**: 필요 시 적용
- **캐싱 전략**: Service Worker (선택사항)

### 2. SEO 및 메타 태그
- Open Graph 메타 태그 (카카오톡 공유 시 미리보기)
- 타이틀, 설명, 이미지 설정
- Favicon 설정

### 3. 브라우저 호환성
- Chrome, Safari, Samsung Internet 지원
- iOS Safari 특히 고려 (한국 사용자 다수)

### 4. 접근성
- 시맨틱 HTML 사용
- Alt 텍스트 설정
- 키보드 네비게이션 지원

## ⚠️ 주의사항

1. **개인정보 보호**: 전화번호, 계좌번호 등 민감 정보는 이미지로 처리하거나 부분 마스킹 고려
2. **이미지 용량**: 갤러리 이미지는 1MB 이하로 최적화
3. **카카오톡 공유**: Kakao Developers에 앱 등록 필요
4. **지도 API**: 네이버/카카오 지도 API 키 발급 필요
5. **GitHub Pages**: HTTPS 자동 적용, 커스텀 도메인 연결 가능
