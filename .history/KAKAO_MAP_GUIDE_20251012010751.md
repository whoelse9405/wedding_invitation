# 카카오맵 사용 가이드

## 현재 설정 상태

카카오맵이 이미 설정되어 있으며, 아르베 웨딩홀 위치가 지도에 표시됩니다.

## 장소 정보 변경 방법

다른 예식장으로 변경하려면 `src/components/Location.tsx` 파일을 수정하세요:

```typescript
const venueName = '예식장 이름';
const venueAddress = '서울특별시 강남구 봉은사로 302';
const venuePhone = '02-564-7031';
const venueFloor = '3층 그랜드홀';

// 좌표 변경
const lat = 37.508705;  // 위도
const lng = 127.039438; // 경도
```

## 좌표 찾는 방법

### 1. 카카오맵에서 좌표 찾기
1. https://map.kakao.com/ 접속
2. 예식장 이름 검색
3. 장소 클릭
4. 주소 오른쪽의 좌표 복사 또는 URL에서 확인

### 2. 네이버 지도에서 좌표 찾기
1. https://map.naver.com/ 접속
2. 예식장 이름 검색
3. 우클릭 → "여기가 어딘가요?" 클릭
4. 좌표 확인 (위도, 경도)

### 3. 구글 맵에서 좌표 찾기
1. https://maps.google.com/ 접속
2. 예식장 이름 검색
3. 장소 클릭
4. URL에서 좌표 확인 (예: @37.508705,127.039438)

## 카카오 API 키 변경 (필요시)

현재 앱에는 카카오 API 키가 설정되어 있습니다. 
새로운 키를 발급받으려면:

1. https://developers.kakao.com/ 접속
2. 내 애플리케이션 → 앱 추가하기
3. JavaScript 키 복사
4. `index.html` 파일 수정:

```html
<script type="text/javascript" 
  src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY">
</script>
```

5. Kakao SDK 초기화 부분도 수정:

```html
<script>
  if (!Kakao.isInitialized()) {
    Kakao.init('YOUR_JAVASCRIPT_KEY');
  }
</script>
```

## 지도 추가 기능

### 지도 타입 컨트롤 추가
```typescript
// 지도 타입 컨트롤러 생성
const mapTypeControl = new window.kakao.maps.MapTypeControl();
map.addControl(mapTypeControl, window.kakao.maps.ControlPosition.TOPRIGHT);

// 줌 컨트롤러 생성
const zoomControl = new window.kakao.maps.ZoomControl();
map.addControl(zoomControl, window.kakao.maps.ControlPosition.RIGHT);
```

### 로드뷰 추가
```typescript
// 로드뷰 클라이언트 생성
const roadviewClient = new window.kakao.maps.RoadviewClient();
const roadview = new window.kakao.maps.Roadview(roadviewContainer);

roadviewClient.getNearestPanoId(position, 50, function(panoId) {
  roadview.setPanoId(panoId, position);
});
```

## 문제 해결

### 지도가 표시되지 않을 때
1. 브라우저 콘솔(F12) 확인
2. 카카오맵 API 키 확인
3. 인터넷 연결 확인
4. 좌표가 올바른지 확인

### 마커가 표시되지 않을 때
1. 좌표 값 확인 (위도, 경도 순서)
2. 지도 줌 레벨 조정
3. 콘솔에서 에러 메시지 확인

### 지도가 회색으로 표시될 때
- 페이지 로드 후 지도 컨테이너 크기 재조정:

```typescript
window.kakao.maps.event.addListener(map, 'tilesloaded', function() {
  map.relayout();
});
```
